# Virtue of Madness: downloads

Beta builds of **Virtue of Madness**, a cosy farming game with mining, fishing, wild lands to explore, a story with a twist, and a card game at the village inn.

## Download and play (Windows)

1. Open the **[latest release](../../releases/latest)** and download `Virtue-of-Madness-<version>-windows-x64.zip` (about 1.3 GB).
2. Right-click the zip and choose **Extract All**. Don't run it from inside the zip.
3. Open the extracted folder and run **Virtue of Madness <version>.exe**.
4. If Windows says "Windows protected your PC", click **More info → Run anyway**. The game isn't code-signed yet.

F11 toggles full screen. Your saves are stored on your own PC and carry over when you install a newer version.

## Updates

Every new version appears on the [Releases](../../releases) page, with a list of what changed. Download the newest zip and extract it. Your save files stay where they are.
